User Purchase Behavior Analysis

Project Overview
This project explores and analyzes user purchase behavior using transactional data. The objective is to uncover patterns in customer spending, identify key behavioral trends, and gain insights that could support business decision-making.

The analysis follows a complete data science workflow, including data cleaning, exploratory data analysis (EDA), and interpretation of results.

Objectives
- Analyze user purchasing patterns
- Identify trends in spending behavior
- Examine relationships between features
- Extract meaningful business insights from the dataset

Dataset
The dataset contains structured information about user purchases. It includes various attributes related to customer activity and purchasing behavior.

Tools & Technologies
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib 

Key Analysis Steps
1. Data inspection and preprocessing  
2. Handling missing or inconsistent values  
3. Exploratory Data Analysis (EDA)  
4. Visualization of user behavior trends  
5. Insight generation and interpretation
